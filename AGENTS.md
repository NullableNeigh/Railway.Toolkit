`../Railway.Toolkit.Management/projects/Railway.Toolkit/AGENTS.md`

Before inspecting, planning, or changing this repository:

1. Confirm `../Railway.Toolkit.Management` exists.
2. Run `pwsh -NoProfile -File ../Railway.Toolkit.Management/scripts/Test-ProjectSynchronization.ps1 -Project Railway.Toolkit` from this repository root.
3. Stop and explain the missing path or synchronization failure if the command does not pass.
4. When it passes, read and follow the private project instructions. Those instructions route to suite-wide policy, project documents, and project-owned skills.

Do not copy, quote, summarize, commit, or publish private management content in this repository. The public source repository contains application and package material only; the sibling private repository owns its agent-management layer.
